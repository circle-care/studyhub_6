Cartesian, polar, and exponential — three ways to write the same number
Main points

Cartesian form: \(z = a + bi\)

Polar form: \(z = r(\cos\theta + i\sin\theta)\), where \(r = |z|\)

Exponential form: \(z = re^{i\theta}\)

Euler's formula: \(e^{i\theta} = \cos\theta + i\sin\theta\)

Polar multiplication: \(zw = rs\big(\cos(\theta+\phi) + i\sin(\theta+\phi)\big)\)

Polar division: \(\dfrac{z}{w} = \dfrac{r}{s}\big(\cos(\theta-\phi) + i\sin(\theta-\phi)\big)\)

Examples / Explanation
Convert \(z = 1+i\) to polar/exponential form: \[r = \sqrt{2}, \quad \theta = \frac{\pi}{4}\] \[z = \sqrt2\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right) = \sqrt2\,e^{i\pi/4}\]
Multiply \(z = 2e^{i\pi/6}\) and \(w = 3e^{i\pi/3}\): \[zw = 6\,e^{i(\pi/6+\pi/3)} = 6e^{i\pi/2} = 6i\]
Trig identities from Euler's formula: \[\cos\theta = \frac{e^{i\theta}+e^{-i\theta}}{2}, \qquad \sin\theta = \frac{e^{i\theta}-e^{-i\theta}}{2i}\]
Helpful points
Exponential form turns multiplication/division into just adding/subtracting angles — much faster than expanding Cartesian brackets.
Always work in radians unless a question specifically says degrees.
\(r\) must be non-negative — if you get a negative "\(r\)", add \(\pi\) to \(\theta\) and flip the sign instead.
