Part 3 of 6: Modulus & argument

Complex Numbers · Part 3

Measuring a complex number: distance and direction

Two new quantities that describe every complex number just as well as \(a\) and \(b\) do.

📝 View the quick-reference notes sheet for this topic →

Modulus: how far from the origin?

Once you're thinking of \(z=a+bi\) as the point \((a,b)\) on the Argand diagram, a very natural question is: how far is that point from the origin? By Pythagoras' theorem (the point, the horizontal distance \(a\), and the vertical distance \(b\) form a right-angled triangle), that distance is:

\[|z| = \sqrt{a^2+b^2}\]

This is called the modulus of \(z\). It's always a non-negative real number, and it's zero only when \(z=0\).

Worked example
Find \(|3+4i|\): \[|3+4i| = \sqrt{3^2+4^2} = \sqrt{9+16} = \sqrt{25} = 5\]

Argument: which direction?

Distance alone doesn't pin down a point — you also need a direction. The argument of \(z\), written \(\arg(z)\) or just \(\theta\), is the angle measured from the positive real axis (counterclockwise) to the line joining the origin to \(z\).

You can find it using basic trigonometry: if \(z=a+bi\) sits at angle \(\theta\) and distance \(r\) from the origin, then \(a = r\cos\theta\) and \(b=r\sin\theta\), which rearranges to give \(\theta = \arctan(b/a)\) — with a catch, covered below.

The quadrant trap: your calculator's \(\arctan\) function only ever returns angles between \(-90°\) and \(90°\) — it has no way of knowing which quadrant your point is actually in. If \(z\) is in the 2nd or 3rd quadrant, the raw \(\arctan(b/a)\) answer will be wrong and needs adjusting by \(180°\) (\(\pi\) radians). Always sketch the point first so you know which quadrant to expect the answer in.
Worked example
Find the argument of \(z=-1-i\).

Naively, \(\arctan(\frac{-1}{-1}) = \arctan(1) = \frac{\pi}{4}\). But \(z=-1-i\) has both parts negative, so it's actually in the third quadrant — nowhere near \(\frac{\pi}{4}\), which is in the first quadrant. The correct angle is found by subtracting \(\pi\):

\[\text{Arg}(z) = \frac{\pi}{4}-\pi = -\frac{3\pi}{4}\]

The "principal" argument

Here's a subtlety: angles repeat every full turn, so \(\theta\), \(\theta+2\pi\), \(\theta-2\pi\), and so on, all point in exactly the same direction. That means every non-zero complex number technically has infinitely many valid arguments.

To avoid ambiguity, mathematicians pick one "canonical" choice called the principal argument, written \(\text{Arg}(z)\) with a capital A, restricted to the range \((-\pi, \pi]\). Unless a question says otherwise, this is the value you should give.

A shortcut for modulus using conjugates

Remember from Part 1 that \(z\bar z = a^2+b^2\)? That's exactly \(|z|^2\). So:

\[z\bar z = |z|^2\]

This can occasionally save you a step, especially in proofs, since it avoids the square root until the very end.

Try it: Find the modulus and principal argument of \(z = 1+i\sqrt3\).
Show answer
\[|z| = \sqrt{1^2+(\sqrt3)^2} = \sqrt{1+3} = \sqrt4 = 2\] \[\theta = \arctan\!\left(\frac{\sqrt3}{1}\right) = \frac{\pi}{3}\] Since \(z\) is in the 1st quadrant (both parts positive), no adjustment is needed: \(\text{Arg}(z) = \frac{\pi}{3}\).
Try it: What is \(|3-4i|\)?
Show answer
\[|3-4i| = \sqrt{3^2+(-4)^2} = \sqrt{9+16} = \sqrt{25} = 5\] (The sign of the imaginary part doesn't matter for the modulus, since it gets squared.)
