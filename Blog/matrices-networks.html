Matrices as a map of connections

Using a matrix to represent a network of routes or links — and what multiplying it by itself reveals.

📝 View the quick-reference notes sheet for this topic →

Representing a network as a matrix

A network — think of towns connected by roads, or webpages connected by links — can be represented as a grid where row \(i\), column \(j\) records whether (or how many ways) you can get directly from point \(i\) to point \(j\).

For this network (A connects to B and C, B connects to C), the matrix — reading row = "from", column = "to" — would be:

\[M = \begin{pmatrix} & A & B & C \\ A & 0 & 1 & 1 \\ B & 0 & 0 & 1 \\ C & 0 & 0 & 0 \end{pmatrix}\]

Entry \(M_{ij}=1\) means there's a direct connection from point \(i\) to point \(j\); \(M_{ij}=0\) means there isn't one. The main diagonal is usually all zeros, since a point doesn't normally connect directly to itself.

What squaring the matrix tells you

Here's the payoff for representing a network this way: computing \(M^2\) (multiplying the matrix by itself, using the row-times-column method from Part 2) tells you the number of two-step routes between any two points.

Worked example

Using \(M\) from above, the entry in row A, column C of \(M^2\) is found the usual way (row A of \(M\) times column C of \(M\)):

\[(0)(1)+(1)(1)+(1)(0) = 1\]

This "1" means there's exactly one two-step route from A to C — going A → B → C.

Remember the network's matrix isn't necessarily symmetric — a connection from A to B doesn't automatically mean there's one from B to A (think one-way streets, or a link on a webpage that doesn't link back). Always keep track of which direction "from" and "to" refer to in your rows and columns.

Try it yourself

Try it: For the network above, how many two-step routes are there from B to itself?
Show answer
Look at row B, column B of \(M^2\): row B of \(M\) is \((0,0,1)\), column B of \(M\) is \((1,0,0)\). \[(0)(1)+(0)(0)+(1)(0) = 0\] So there are no two-step routes from B back to itself in this particular network.
