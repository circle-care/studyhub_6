Matrices · Part 4

Using matrices to solve systems of equations

Turning a whole system of simultaneous equations into one matrix equation — and solving it in one step.

📝 View the quick-reference notes sheet for this topic →

Rewriting a system as a matrix equation

Take a pair of simultaneous equations:

\[3x+2y=16 \qquad x+4y=18\]

This can be rewritten as a single matrix equation \(A\mathbf{x}=\mathbf{b}\), by pulling the coefficients into a matrix, and the unknowns and constants into column vectors:

\[\begin{pmatrix}3&2\\1&4\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}16\\18\end{pmatrix}\]

Check this actually reproduces the original equations by multiplying out the left-hand side using the row-times-column method from Part 2 — you should get back \(3x+2y\) and \(x+4y\), matching the original system exactly.

Solving using the inverse

Once written as \(A\mathbf{x}=\mathbf{b}\), you solve for \(\mathbf{x}\) the same way you'd solve \(ax=b\) for an ordinary number — by "dividing" both sides by \(A\), which for matrices means multiplying by \(A^{-1}\):

\[\mathbf{x} = A^{-1}\mathbf{b}\]

Order matters here — you must multiply \(A^{-1}\) on the left of \(\mathbf{b}\), matching how it appears on the left of \(\mathbf{x}\) in the original equation. Matrix multiplication isn't commutative, so \(\mathbf{b}A^{-1}\) generally isn't even defined, let alone equal to the right thing.
Worked example

Using \(A=\begin{pmatrix}3&2\\1&4\end{pmatrix}\) from above (which has \(\det(A)=10\), from Part 3):

\[A^{-1} = \frac{1}{10}\begin{pmatrix}4&-2\\-1&3\end{pmatrix}\]

So:

\[\mathbf{x} = \frac{1}{10}\begin{pmatrix}4&-2\\-1&3\end{pmatrix}\begin{pmatrix}16\\18\end{pmatrix} = \frac{1}{10}\begin{pmatrix}(4)(16)+(-2)(18)\\(-1)(16)+(3)(18)\end{pmatrix} = \frac{1}{10}\begin{pmatrix}28\\38\end{pmatrix} = \begin{pmatrix}2.8\\3.8\end{pmatrix}\]

So \(x=2.8\), \(y=3.8\). You can always check this by substituting back into the original two equations.

When this method fails

Remember from Part 3: if \(\det(A)=0\), then \(A\) has no inverse — which means this method can't be used at all. Geometrically, this happens when the system either has no solutions (the equations contradict each other) or infinitely many solutions (the equations are really the same line/plane in disguise).

Try it: Rewrite \(2x-y=7\) and \(3x+y=8\) as a matrix equation \(A\mathbf{x}=\mathbf{b}\).
Show answer
\[\begin{pmatrix}2&-1\\3&1\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}7\\8\end{pmatrix}\]
Try it: Solve that same system using the inverse method. (First find \(\det(A)\) and \(A^{-1}\).)
Show answer
\[\det(A) = (2)(1)-(-1)(3) = 2+3=5\] \[A^{-1} = \frac{1}{5}\begin{pmatrix}1&1\\-3&2\end{pmatrix}\] \[\mathbf{x} = \frac{1}{5}\begin{pmatrix}1&1\\-3&2\end{pmatrix}\begin{pmatrix}7\\8\end{pmatrix} = \frac{1}{5}\begin{pmatrix}15\\-5\end{pmatrix} = \begin{pmatrix}3\\-1\end{pmatrix}\] So \(x=3\), \(y=-1\).
