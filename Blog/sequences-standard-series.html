Formulas worth memorising: standard sums

Ready-made formulas for common sums, and the rules for manipulating and combining them.

📝 View the quick-reference notes sheet for this topic →

The four standard sums

These four formulas come up constantly, and are worth memorising outright rather than deriving each time:

\[\sum_{k=1}^{n} 1 = n\] \[\sum_{k=1}^{n} k = \frac{n(n+1)}{2}\] \[\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\] \[\sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2\]
Worked example
Find \(\displaystyle\sum_{k=1}^{5}k^2\) using the formula: \[\frac{5(6)(11)}{6} = \frac{330}{6}=55\] Check by adding directly: \(1+4+9+16+25=55\) ✓

Manipulation rules

These formulas become much more powerful once combined with a few manipulation rules:

Constant multiple: \(\displaystyle\sum_{k=1}^n ca_k = c\sum_{k=1}^n a_k\) (pull a constant factor outside the sum)

Sum/difference: \(\displaystyle\sum_{k=1}^n(a_k+b_k) = \sum_{k=1}^n a_k+\sum_{k=1}^n b_k\) (split a sum of sums into separate sums)
Worked example
Find \(\displaystyle\sum_{k=1}^{4}(3k^2+2)\):

Split using the sum/difference rule, then pull out the constant:

\[3\sum_{k=1}^4 k^2 + \sum_{k=1}^4 2\]

Using the standard formulas (\(n=4\) throughout):

\[3\left(\frac{4(5)(9)}{6}\right) + 4(2) = 3(30)+8 = 90+8=98\]

When the sum doesn't start at k = 1

The standard formulas all assume the sum starts at \(k=1\). If a question gives you a sum starting somewhere else — like \(\displaystyle\sum_{k=4}^{10}k^2\) — split it as a difference of two sums that do start at 1:

\[\sum_{k=4}^{10}k^2 = \sum_{k=1}^{10}k^2 - \sum_{k=1}^{3}k^2\]

When splitting this way, the second sum stops one below where your original sum started (here, stopping at \(k=3\) since the original started at \(k=4\)) — not at the same starting value.
Try it: Evaluate \(\displaystyle\sum_{k=1}^{6}k\) using the standard formula.
Show answer
\[\frac{6(7)}{2} = 21\]
Try it: Evaluate \(\displaystyle\sum_{k=5}^{8}k^2\) by splitting into two sums starting at 1.
Show answer
\[\sum_{k=5}^{8}k^2 = \sum_{k=1}^{8}k^2 - \sum_{k=1}^{4}k^2 = \frac{8(9)(17)}{6} - \frac{4(5)(9)}{6} = 204-30=174\]
