Networks: representing, calculating outputs, combining
Main points

A network is a set of nodes connected by arcs. Arrows show direction of flow; labels on each arc give the proportion of the input travelling that path.

Building the matrix:
\(n\) input nodes, \(m\) output nodes → matrix is \(m\times n\).
Each column = one input node.
Each row = one output node.
Entry \((i,j)\) = label on the arc from input \(j\) to output \(i\).
Column sum property: every column must sum to 1 — an input node's flow splits into proportions of its own total, so those proportions must add up to the whole thing.
Examples / explanation

Converting a diagram to a matrix:

2 input nodes, 2 output nodes: \(I_1\) splits 0.6 to \(O_1\), 0.4 to \(O_2\). \(I_2\) splits 0.3 to \(O_1\), 0.7 to \(O_2\).
Columns = inputs (\(I_1, I_2\)), rows = outputs (\(O_1,O_2\)): \[ M = \begin{pmatrix} 0.6 & 0.3 \\ 0.4 & 0.7 \end{pmatrix} \] Check: column 1 sums to \(0.6+0.4=1\) ✓. Column 2 sums to \(0.3+0.7=1\) ✓.

Calculating outputs from an input vector:

Suppose 100 litres enter at \(I_1\) and 50 litres at \(I_2\): \[ \mathbf{i} = \begin{pmatrix} 100 \\ 50 \end{pmatrix} \] \[ \mathbf{o} = M\mathbf{i} = \begin{pmatrix} 0.6 & 0.3 \\ 0.4 & 0.7 \end{pmatrix}\begin{pmatrix} 100 \\ 50 \end{pmatrix} = \begin{pmatrix} 60+15 \\ 40+35 \end{pmatrix} = \begin{pmatrix} 75 \\ 75 \end{pmatrix} \] 75 litres reach \(O_1\), 75 litres reach \(O_2\). Check: total in \(=150\), total out \(=150\) ✓.

Combining two networks — mind the order:

Network \(A\) flows first, then feeds into network \(B\). The combined matrix is \(BA\) — not \(AB\) — since \(A\) is applied to the input first: \((BA)\mathbf{i} = B(A\mathbf{i})\), matching the actual order things happen in.
Helpful points
Easy mistake: writing \(AB\) instead of \(BA\) for "A then B." Always ask "which matrix gets applied to the raw input first?" — that one goes on the right in the product.
Use the column-sum-to-1 check on every network matrix you build — an instant way to catch a mislabelled arc before it causes problems downstream.
Total input should always equal total output for these proportion-based networks (nothing created or lost) — a fast sanity check on your final answer vector.

Combining networks via matrix multiplication avoids tracing every possible route by hand — for anything beyond 2 nodes, the route-by-route method gets tedious fast, while \(BA\) gives the simplified network instantly.
