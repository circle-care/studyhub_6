Standard finite series formulas & manipulation rules
Main points
Four standard finite series: \[ \sum_{k=1}^{n} 1 = n \] \[ \sum_{k=1}^{n} k = \frac{1}{2}n(n+1) \] \[ \sum_{k=1}^{n} k^2 = \frac{1}{6}n(n+1)(2n+1) \] \[ \sum_{k=1}^{n} k^3 = \frac{1}{4}n^2(n+1)^2 \]
Manipulation rules:
Constant multiple: \(\sum ck = c\sum k\)
Sum/difference: \(\sum(x_k\pm y_k) = \sum x_k \pm \sum y_k\)
Splitting: \(\displaystyle\sum_{k=p}^{q}x_k = \sum_{k=1}^{q}x_k - \sum_{k=1}^{p-1}x_k\)
Examples / explanation

Why \(\sum k = \frac12 n(n+1)\) — the geometric reasoning:

Picture an \(n\times(n+1)\) grid of dots. Splitting it diagonally gives two identical triangular halves, each containing \(1+2+3+\cdots+n\) dots. So the full sum equals half the total grid: \(\frac{1}{2}n(n+1)\). This is the classic "pair up first and last" trick (e.g. Gauss's method: \(1+n\), \(2+(n-1)\), etc., each pair summing to \(n+1\)) shown visually.

Direct application — sum of squares:

Find \(1^2+2^2+\cdots+10^2\): \[ \sum_{k=1}^{10}k^2 = \frac{1}{6}(10)(11)(21) = \frac{2310}{6} = 385 \]

Constant multiple rule in action:

Find \(\displaystyle\sum_{k=1}^{5}3k\): \[ \sum_{k=1}^{5}3k = 3\sum_{k=1}^{5}k = 3\left(\frac{1}{2}(5)(6)\right) = 3(15) = 45 \]

Sum/difference rule — combining standard series:

Find \(\displaystyle\sum_{k=1}^{4}(k^2+2k)\): \[ \sum_{k=1}^{4}k^2 + 2\sum_{k=1}^{4}k = \frac{1}{6}(4)(5)(9) + 2\left(\frac{1}{2}(4)(5)\right) \] \[ = 30 + 20 = 50 \]

Splitting rule — lower limit isn't 1:

Find \(\displaystyle\sum_{k=4}^{8}k^2\) — starts at \(k=4\), not \(k=1\). \[ \sum_{k=4}^{8}k^2 = \sum_{k=1}^{8}k^2 - \sum_{k=1}^{3}k^2 \] \[ = \frac{1}{6}(8)(9)(17) - \frac{1}{6}(3)(4)(7) = 204 - 14 = 190 \]
Helpful points
For the splitting rule, subtract up to \(p-1\), not \(p\) — if you started summing at \(k=4\), you need everything from \(k=1\) to \(k=3\) removed (i.e. up to \(p-1=3\)), not up to \(k=4\), or you'll accidentally remove the \(k=4\) term you actually wanted to keep.
Strategy for any "complicated" series: split it into standard pieces first (using sum/difference and constant multiple), then apply the standard formulas to each piece separately, then combine.
\(\sum_{k=1}^n 1 = n\) looks almost too simple to be useful, but shows up constantly when a series has a plain constant term mixed in — e.g. \(\sum(k^2+5)\) needs this formula for the "+5" part.
