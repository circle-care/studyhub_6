Long-term behaviour and convergence
Main points

A sequence is increasing if each term is bigger than the last, decreasing if each is smaller. Bounded means it never goes beyond some fixed value in either direction; unbounded means it does.

A sequence converges to a limit \(L\) if \(a_n \to L\) as \(n\to\infty\) — the terms get arbitrarily close to \(L\) and stay close.
Arithmetic: always tends to \(+\infty\) or \(-\infty\) unless \(d=0\) (constant sequence).

Geometric: converges to 0 only if \(|r|<1\). If \(|r|>1\), unbounded.
Examples / explanation

Arithmetic, always diverges (unless \(d=0\)):

\(a_n = 5+3(n-1)\): as \(n\to\infty\), terms grow without bound → \(a_n\to+\infty\). If \(d\) were negative, e.g. \(a_n=20-2(n-1)\), it heads to \(-\infty\) instead. Either way, it never settles on a finite limit unless \(d=0\).

Geometric, \(|r|<1\) — converges to 0:

\(a_n = 100(0.5)^{n-1}\): \(100, 50, 25, 12.5, \ldots \to 0\). Each term is smaller in magnitude, since multiplying repeatedly by a number between \(-1\) and \(1\) shrinks it toward zero.

Geometric, \(|r|>1\) — unbounded:

\(a_n = 3(2)^{n-1}\): \(3,6,12,24,48,\ldots\to\infty\). Multiplying repeatedly by something bigger than 1 (in magnitude) makes it grow forever.

Geometric with negative ratio, \(-1

\(a_n = 8(-0.5)^{n-1}\): \(8, -4, 2, -1, 0.5, -0.25,\ldots\) — oscillates in sign, but the magnitude still shrinks toward 0 since \(|r|=0.5<1\). Still converges — to 0.

Finding the smallest \(N\) where a term drops below a threshold:

Find the smallest \(N\) such that \(x_N<1\), given \(x_n = 200\left(\frac14\right)^{n-1}\). \[ 200\left(\frac14\right)^{n-1} < 1 \;\Rightarrow\; \left(\frac14\right)^{n-1} < \frac{1}{200} \] Take logs of both sides: \[ (n-1)\ln\left(\frac14\right) < \ln\left(\frac{1}{200}\right) \] \[ (n-1)(-1.3863) < -5.2983 \] Dividing by a negative number flips the inequality: \[ n-1 > 3.822 \;\Rightarrow\; n > 4.822 \;\Rightarrow\; N=5 \] Check: \(x_5\approx0.781<1\) ✓, \(x_4=3.125\) (not yet under 1) ✓.
Helpful points
\(r=1\) is a trap: \(|r|<1\) is false when \(r=1\) (since \(|1|=1\), not less than 1) — a geometric sequence with \(r=1\) is actually just a constant sequence, and one with \(r=-1\) oscillates between two values forever, converging to neither.
Quick check for geometric convergence: just look at \(|r|\). \(|r|<1\) → converges to 0. \(|r|\geq1\) → does not converge (diverges or oscillates).
Solving for a smallest \(N\): whenever you divide an inequality by \(\ln r\) (negative when \(0must flip the inequality sign — the single most common mistake in this type of question. Always round the final answer up to the next whole number, since you need the smallest integer satisfying "greater than."
Arithmetic sequences never converge to a finite limit (except the trivial \(d=0\) case) — this is a completely different long-term behaviour from geometric sequences, which frequently do converge.
\(|r|\)Behaviour
\(|r|<1\)Converges to 0
\(|r|=1\)Constant or oscillates
\(|r|>1\)Unbounded
