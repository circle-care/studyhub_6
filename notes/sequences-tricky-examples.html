Trickiest worked examples, step by step
Main points

Five techniques that catch people out most often across the whole unit:

1. Shifting a closed form to start at a different index (e.g. \(n=1\) → \(n=0\)).
2. Long-term behaviour of a combined sequence (geometric part + constant part).
3. Recurring decimal → fraction, using the infinite geometric series formula.
4. Coefficient of a term with two variable powers, like \(x^{12}y^9\).
5. Coefficient of a single power (e.g. \(p^4\)) when both binomial terms contain variables.
Examples / explanation

1. Shifting the starting index:

A sequence has closed form \(a_n = 3n+2\) starting at \(n=1\) (so \(a_1=5, a_2=8,\ldots\)). Rewrite it to start at \(n=0\) instead, describing the same sequence of values.

Let the new index be \(m=n-1\), so \(n=m+1\). Substitute: \[ a_m = 3(m+1)+2 = 3m+5 \] Check: at \(m=0\), \(a_0=5\) — matches the original \(a_1=5\) ✓. At \(m=1\), \(a_1=8\) — matches original \(a_2=8\) ✓. Same sequence, just relabelled.

2. Long-term behaviour of a combined sequence:

Find the long-term behaviour of \(a_n = 5 + 20(0.6)^{n-1}\) as \(n\to\infty\).

Break it into pieces: the geometric part \(20(0.6)^{n-1}\) has \(|r|=0.6<1\), so it \(\to0\). The constant \(5\) never changes. \[ a_n \to 5+0 = 5 \] So \(a_n\to5\) — the sequence converges to 5, even though it's not a "pure" geometric sequence on its own.

3. Recurring decimal via geometric series:

Convert \(0.\overline{27}=0.272727\ldots\) to a fraction using series, not the algebra-subtraction method.

Write it as an infinite geometric series: \(0.27+0.0027+0.000027+\cdots\), so \(a=0.27\), \(r=0.01\) (each term is \(\frac1{100}\) of the last). \[ S_\infty = \frac{a}{1-r} = \frac{0.27}{1-0.01} = \frac{0.27}{0.99} = \frac{27}{99} = \frac{3}{11} \]

4. Term with two variable powers:

Find the coefficient of \(x^{5}y^{3}\) in \((x+y)^8\).

Since \(n=8\) and the two powers must add to \(n\) (\(5+3=8\) ✓), set \(k=3\) (matching \(y\)'s power): \[ \binom{8}{3}x^{8-3}y^3 = \binom{8}{3}x^5y^3 \] \[ \binom{8}{3} = \frac{8!}{3!\,5!} = 56 \] Coefficient is 56.

5. Specific power when both terms have variables:

Find the coefficient of \(p^4\) in \((2p-q)^7\), leaving \(q\) as a symbol in the answer.

Here \(a=2p\), \(b=-q\), \(n=7\). We want \(p\) to have power 4 — since \(p\) only comes from the \(a^{n-k}=(2p)^{n-k}\) part, set \(n-k=4 \Rightarrow k=3\): \[ \binom{7}{3}(2p)^{4}(-q)^{3} = \binom{7}{3}(16p^4)(-q^3) \] \[ \binom{7}{3}=35, \qquad 35\times16\times(-1) = -560 \] Term is \(-560\,p^4q^3\) — coefficient \(-560\), and \(q^3\) stays attached since the question only fixed the power of \(p\).
Helpful points
Index shifting (Ex 1): always substitute and then check two values against the original — a single check can hide a sign error.
Combined sequences (Ex 2): only the non-constant (geometric or arithmetic) part determines convergence — a plain added constant just becomes part of the final limit, never changes whether it converges.
Recurring decimals (Ex 3): \(r\) is a power of \(\frac1{10}\) matching how many digits repeat (\(r=0.1\) for 1 digit, \(r=0.01\) for 2 digits, etc.) — not the decimal value itself.
Two-variable terms (Ex 4): always check the two powers add to \(n\) first — free confirmation you've set up \(k\) correctly before computing anything.
Variables in both terms (Ex 5): figure out which variable the question is asking about, then use that variable's exponent to pin down \(k\) — don't default to matching \(b\)'s power out of habit.
