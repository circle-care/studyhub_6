Continuity & the Limit Laws
Sum, Difference & Product Rules

If f and g are continuous at a, then so are f + g, f − g, and f · g.

Why: the limit of a sum/product equals the sum/product of the limits.
So limx→a h(x) = h(a) automatically follows.
Any polynomial is continuous on the entire real line — built from constants and x using only sums and products.

Example: 5x² is continuous everywhere (product of continuous 5 and continuous x·x). 5x² + x is continuous everywhere (sum of continuous functions).

Quotient Rule

If f and g are continuous at a and g(a) ≠ 0, then f/g is continuous at a.

The quotient is only continuous where it's defined — i.e. where the denominator isn't zero.

Example: tan x = sin x / cos x. Both sine and cosine are continuous everywhere, so tan x is continuous everywhere except where cos x = 0, i.e. x = ±π/2, ±3π/2, …

Example: 1/(x² + 1) — polynomial over polynomial, and x² + 1 is never zero, so this is continuous everywhere, no exceptions.

Composition Rule

If g is continuous at a, and f is continuous at g(a), then the composition f∘g is continuous at a.

As x → a: g(x) → g(a), and since f is continuous at g(a), f(g(x)) → f(g(a)).
So h(x) = f(g(x)) → h(a).

Example: sin(x² + 1) — inner function x² + 1 is a continuous polynomial, outer function sin is continuous everywhere, so the composition is continuous everywhere.

Sum, difference, product, quotient (where defined), and composition of continuous functions are all continuous. This covers virtually every function you'll build in this course.
