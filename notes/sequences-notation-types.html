Specifying sequences, arithmetic & geometric patterns
Main points

A sequence is a list of terms \(a_n\), one for each integer index \(n\). Three ways to define one:

1. Listing terms: give the first few, assume the pattern continues.
2. Closed form: a formula for \(a_n\) directly in terms of \(n\).
3. Recurrence: \(a_n\) defined using \(a_{n-1}\), plus a starting term.
Arithmetic: add a fixed common difference \(d\) each time. \[ x_n = a + (n-1)d \]
Geometric: multiply by a fixed common ratio \(r\) each time. \[ x_n = ar^{n-1} \]
Examples / explanation

Listing terms:

\(2, 4, 6, 8, \ldots\) — assumed pattern: add 2 each time. Risky if the pattern isn't actually obvious or unique from just a few terms!

Closed form:

\(a_n = 3n+1\) → instantly gives \(a_1=4\), \(a_{10}=31\), \(a_{100}=301\) — no need to know earlier terms at all.

Recurrence:

\(a_1 = 5\), \(a_n = a_{n-1}+3\) → each term needs the previous one computed first: \(a_2=8\), \(a_3=11\), \(a_4=14\), etc.

Arithmetic sequence example:

\(a=5\), \(d=3\): \(5,8,11,14,17,\ldots\) \[ x_n = 5+(n-1)(3) \] \(x_{10} = 5+(9)(3) = 32\)

Geometric sequence example:

\(a=3\), \(r=2\): \(3,6,12,24,48,\ldots\) \[ x_n = 3(2)^{n-1} \] \(x_6 = 3(2)^5 = 3(32) = 96\)

From listed terms to a recurrence system:

Given the first four terms \(5, 15, 45, 135, \ldots\), find \(a\), \(r\), and write the recurrence.

\(a = x_1 = 5\) (just the first term).

\(r\) = any term ÷ the one before it: \[ r = \frac{15}{5} = 3 \] Check with another pair: \(\dfrac{45}{15}=3\), \(\dfrac{135}{45}=3\) ✓ — confirms it really is geometric.

Recurrence system: \[ x_1 = 5, \qquad x_n = 3x_{n-1} \quad (n\geq2) \]
Helpful points
Listing terms alone is ambiguous — \(2,4,6,8\) could continue \(10,12,\ldots\) (arithmetic) or could be something else entirely. Always prefer a closed form or recurrence when precision matters.
Spot which type quickly: constant difference between consecutive terms → arithmetic. Constant ratio between consecutive terms → geometric.
\(x_n = a+(n-1)d\) uses \((n-1)\), not \(n\) — because the first term \(x_1\) shouldn't have \(d\) added at all: \(x_1 = a+(0)d = a\). Same reasoning for \(r^{n-1}\) in geometric.
When finding \(r\) from listed terms, always check it with more than one pair of consecutive terms. If the ratios don't match, either it isn't truly geometric, or there's an error somewhere in the given terms.
